# Financial Asset Management Web Application

A simple web application for managing your financial assets (bank accounts, investment accounts, etc.) using HTML, CSS, and JavaScript with Firebase Realtime Database.

## Overview

This application allows you to:
- Add and manage multiple accounts (bank accounts, investment accounts, etc.)
- Record and update account balances irregularly as needed
- View your total assets across all accounts
- Visualize asset distribution and trends with charts
- Track balance history for each account

## Features

- **Account Management**: Add, edit, and delete accounts
- **Balance Tracking**: Input and update balances for each account
- **Dashboard**: View total assets and account-wise balances
- **Charts**: Visualize asset distribution and balance trends
- **History**: Track balance changes over time

## Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend**: Firebase Realtime Database
- **Charts**: Chart.js

## Quick Start

1. Clone or download this repository
2. Set up Firebase Realtime Database (see [SETUP.md](SETUP.md) for details)
3. Configure Firebase credentials in your project
4. Open `index.html` in a web browser

For detailed setup instructions, please refer to [SETUP.md](SETUP.md).
